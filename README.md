📌 Detector de Fake News — Projeto de Extensão IESB
Um projeto de extensão voltado à identificação automática de notícias falsas (Fake News), combinando tecnologia focada em ciência de dados.
Nosso objetivo é promover o pensamento crítico e combater a desinformação com ferramentas acessíveis à comunidade.
